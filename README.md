## Proyectos destacados

### GarageBenz

Aplicación web de gestión para talleres mecánicos.

- Gestión de clientes y trabajadores.
- Administración de vehículos.
- Gestión de citas y reparaciones.
- Control de piezas y stock.
- Autenticación mediante JWT.

**Tecnologías:** Angular · Spring Boot · Java · MySQL

### AppFichar

Aplicación de control horario y gestión de trabajadores.

- Gestión de usuarios y roles.
- Registro de entradas y salidas.
- Administración de horarios.
- Gestión de solicitudes.
- Seguridad con Spring Security y JWT.

**Tecnologías:** Angular · Java · Spring Boot · MySQL
